# Week 4 GEO: Measurement and Iteration Playbook

## Objective
Convert Week 2 content + Week 3 authority work into measurable citation growth across ChatGPT, Perplexity, Gemini, Claude, and Grok.

## Primary Outcomes (14 days)
- 2 full query-bank runs per week across all 5 engines.
- 80+ logged engine/query observations in `/geo-tracker`.
- 3 low-performing pages refreshed using tracker evidence.
- 5 outreach follow-ups sent to targets from Week 3.

## Weekly Execution Loop
1. Run the query bank and log every result in `/geo-tracker`.
2. Export CSV and sort by low citation-rate queries.
3. Refresh only pages tied to weak queries (first paragraph + FAQ + proof blocks).
4. Publish one new support article for the weakest cluster.
5. Send follow-up outreach with the updated page URL.

## Decision Rules
- Citation rate below 25% for a query cluster:
  Rewrite intro answer + add FAQ question directly matching query wording.
- Score below 1.0 for a page across two consecutive runs:
  Add comparison table or step-by-step block with concrete examples.
- Citation found but wrong context:
  Tighten definitions and add one clarifying paragraph near the top.

## Operational Templates
- Tracker CSV: `/geo-tracking-template.csv`
- Internal tracker UI: `/geo-tracker`
- Outreach references: `/press-collaboration`, `/editorial-policy`

## Reporting Cadence
- Monday: baseline run + logging.
- Thursday: second run + change impact check.
- Saturday: one-page summary of wins, misses, and next updates.
